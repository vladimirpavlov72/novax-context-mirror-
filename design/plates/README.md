## Правила семьи (анти-список спринта, §7)

Без цен/триала/рейтингов/наград/кнопки «Установить» на кадрах; подписи ≤8
слов, <40 знаков; UI на языке карточки; один мастер-сет 1080×1920 (9:16) на
все 4 стора; Huawei-видео (4:3) и GP feature graphic (1024×500) —
отдельные экспорты позже.
