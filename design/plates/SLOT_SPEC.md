# СПЕКА СЛОТА ВСТАВКИ СКРИНА (пластины кадров, измерено Гиа 25.10)

> Для сборщика кадров (Рома-3, задача в MAILBOX 25.10 22:45).
> Холст пластины: 1080×1920. Слот — пунктирный прямоугольник внутри
> телефонной рамки. Пунктир в финале НЕ виден — скрин ложится ПОВЕРХ.

## Координаты слота (все 4 пластины идентичны)

- Прямоугольник вставки: **x = 192…888, y = 548…1786** (ширина 696, высота 1238).
- Соотношение слота: 696:1238 ≈ **1:1,778** (ровно 16:9... нет, 9:16-вертикаль: 0,562).
- Скрины с 14T: 1080×2400 (0,45) — УЖЕ, чем слот. Значит: **кроп скрина по вертикали**
  до соотношения 0,562 (убрать лишний низ/верх; статус-бар телефона — обрезать в любом случае),
  затем ресайз до 696×1238, вставка по координатам (192, 548).

## Проверка после вставки

- Пунктир не проглядывает ни с одной стороны (при необходимости скрин на 2–4 px больше слота — ок, он на тёмном фоне незаметен).
- Скругления: у слота скруглённые углы (~24 px) — без скругления сойдёт (фон скрина тёмный/светлый ровный), но идеал — лёгкий радиус. Не критично.
- Подпись сверху и бренд-тег — НЕ трогать (они часть пластины).

## Быстрый старт (Pillow)

```python
from PIL import Image
plate = Image.open('design/plates/plate_cleaner_kadr1.png')
shot  = Image.open('design/cleaner/raw/main_dashboard_14t.png')
# 1) кроп скрина до 0.562: целевая высота = ширина / 0.562
w, h = shot.size
target_h = int(w / 0.562)
top = (h - target_h) // 2          # или со сдвигом: убрать статус-бар сверху
shot2 = shot.crop((0, top, w, top + target_h)).resize((696, 1238), Image.LANCZOS)
plate.paste(shot2, (192, 548))
plate.save('design/cleaner/final/kadr1_ru.png')
```
