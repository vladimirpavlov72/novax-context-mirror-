## 3. ASO & RuStore Optimization — Приоритет #1 (Неделя 1)

ASO — единственный бесплатный источник устойчивого органического трафика. Делаем в первую очередь.

### 3.1. Исследование ключевых слов

**Источники:**
- Поисковые подсказки RuStore (вводить запросы и смотреть автодополнение).
- Поисковые подсказки Google/Yandex: «трекер воды», «пить воду», «напоминание пить воду».
- Yandex Wordstat (если доступен): «приложение пить воду», «трекер воды android».
- Топ-5 приложений в RuStore по запросам «трекер воды», «пить воду» — анализ title, подзаголовка, описания.

**Ключевые слова для RuStore (приоритет):**

| Приоритет | Ключевые слова |
|-----------|----------------|
| Высокий | трекер воды, пить воду, напоминание пить воду, приложение пить воду |
| Средний | норма воды в день, трекер воды бесплатно, контроль питьевого режима |
| Long-tail | приложение для питья воды без рекламы, трекер воды без подписок, напоминания о воде android |

**Убраны:** «трекер привычек» (не про воду), «159 рублей» (никто не ищет цену), «hydration tracker русский».

### 3.2. Тексты карточки RuStore

- **Название:** `NOVAX H₂O — трекер воды`
  - Дескриптор в title улучшает индексацию по главному запросу.
- **Подзаголовок:** `Без подписок и рекламы`
- **Короткое описание:** `7 дней бесплатно, потом 159 ₽ разово. Данные только на вашем телефоне.`
- **Полное описание (RU):**
  ```
  NOVAX H₂O — простой трекер воды без подписок и рекламы.

  Что умеет:
  • Рассчитывает персональную норму воды

  ```

### 3.3. Локализация карточки

Подготовить title + short description + полное описание для топ-3 локалей помимо RU:
- **EN:** `NOVAX H₂O — Water Tracker`
- **ES:** `NOVAX H₂O — Rastreador de agua`
- **PT:** `NOVAX H₂O — Rastreador de água`

Это бесплатный трафик из СНГ и других маркетов, где приложение уже поддерживает язык.

### 3.4. Скриншоты

**Требования к скриншотам (критично для RuStore):**
- Разрешение: **1080×1920 (9:16)**.
- Шрифт/размер экрана: **стандартные настройки устройства**.
- Тема: **светлая** (RuStore-приоритет).
- Локаль: **RU** для основного набора, EN/ES/PT для локализованных.
- Без персональных уведомлений, без статус-бара с именами, без лишних UI-элементов.
- Владелец задачи: Владимир / Рома.
- Дедлайн: до конца недели 1.

**5–7 скриншотов 1080×1920** с локализованными подписями:
1. Главный экран с прогрессом + текст «Следи за питьевым режимом».
2. Быстрое добавление воды + текст «+250 / +500 мл в один тап».
3. История + текст «Анализ по дням и неделям».
4. Выбор напитка + текст «Кофе, чай, сок — всё учитывается».
5. Premium-экран + текст «159 ₽ разово. Никаких подписок».
6. Настройки / напоминания + текст «Умные напоминания без назойливости».
7. Тёмная тема + текст «Тёмная тема и 12 языков».

**Видео-превью:** 15–20 сек, демонстрация добавления воды и просмотра истории.

## 7. Trial Conversion & Product Growth

### 7.1. Onboarding

- На 3–4 шаге onboarding показать ценность premium: история, напитки, виджеты.
- Не показывать paywall сразу — сначала ценность.

### 7.2. Push-стратегия во время trial

- **День 3:** напоминание о функции истории.
- **День 5:** мягкий пуш о завершении trial через 2 дня + преимущества premium.
- **День 6:** последнее напоминание + CTA к покупке.
- **День 7:** экран paywall при открытии приложения.

**Подстраховка:** in-app напоминание на главном экране и в history, если push-оптин низкий.

### 7.3. Эксперименты (только после 100+ установок/неделю)

- Тестировать заголовки на paywall: «Полный доступ», «Без ограничений навсегда», «Premium».
- Тестировать CTA: «Купить за 159 ₽», «Получить доступ», «Активировать».
- **Цена не тестируется:** 159 ₽ разово — жёсткое правило бренда.

### 7.4. Промо-механики

- **Реферальная программа:** рекомендация другу с бонусом (позже, после 100+ установок).
- **Промокоды:** для блогеров и каналов (позже).

> **Важно:** цена всегда 159 ₽ разово. Скидки и акции на цену не применяются — это правило бренда.
