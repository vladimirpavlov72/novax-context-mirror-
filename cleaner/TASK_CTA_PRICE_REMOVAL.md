# TASK: Убрать цену с CTA-кнопок Cleaner (решение Владимира, 24.10)

> Статус: в очередь Ромы-2 (платформа/Cleaner), ПОСЛЕ релиза v2.3.0
> (он на модерации — этот фикс уходит в СЛЕДУЮЩУЮ версию, v2.3.1/+2031).
> Свежий контекст Роме-2 — завтра утром.

## Решение Владимира (дословный смысл)

Цена с кнопок-плашек УБИРАЕТСЯ. Пользователь жмёт «Очистить все» — и там
уже аккуратно, подробно разжёвывается: купи премиум ОДИН раз — пользуйся
всю жизнь. Причина (реакция обывателя, зафиксирована с A52, скрин
tg_media/a52_now_1544.png): кнопка «Очистить все • 159 ₽» читается как
«любая чистка за деньги» — обман ожидания, бьёт по доверию и конверсии.

Эталон-правило (в дополнение к «деньги на своём месте воронки»):
**цена живёт в пейволе/диалоге объяснения, НЕ на CTA-кнопках.**

## Что менять (точки найдены Гиа)

1. **results_screen.dart:413** — главная точка: CTA непремиума собирается
   как `'${l10n.cleanAll} • $displayPrice'`. Стало: просто `l10n.cleanAll`
   (без цены; размер в скобках оставить можно — он ценность, а не цена).
2. **Поток после нажатия** (проверить/допилить): диалог/пейвол, который
   открывается по «Очистить все» непремиуму, должен САМ нести полное
   объяснение: что входит в премиум (безлимит всегда + дубликаты/большие/
   кэш приложений), «один раз — навсегда, с обновлениями», цена строкой.
   По канону текстов Владимира, без «мы просим».
3. **Аудит соседних точек** (grep price159Rub дал): results_screen:358
   (displayPrice — оставить для диалога), clean_success_screen:211,
   settings_screen:260 («159 ₽ • разовая покупка» в настройках — это
   информативная строка, НЕ CTA: решение Ромы-2, по умолчанию оставить).
   Принцип: CTA- кнопки без цены; справочные строки — можно.

## DoD

- Кнопки CTA без цены (скрин «до/после» в отчёт).
- Диалог после нажатия с полным честным объяснением + ценой.
- l10n: новые/изменённые ключи во всех 12 локалях (EN — референс).
- analyze 0, тесты зелёные, Z-пакет дельты по регламенту (кросс-паттерн
  paywall — Рома-2 сам решает степень Z-цикла, но релиз без Z не уходит).
