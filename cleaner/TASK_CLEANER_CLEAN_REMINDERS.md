## 1. Цель

Клинер сейчас **никак не напоминает** пользователю о чистке (проверено аудитом:
нет ни пакета уведомлений, ни планировщика; в манифесте заложено
`POST_NOTIFICATIONS` с комментарием «for clean reminders», функция
`requestNotificationPermission()` в `permission_service.dart:177` написана,
но нигде не вызывается — «висячий провод»).

Нужно довести задел до фичи: **максимум 1 напоминание в 30 дней, только при
реальной необходимости, полностью отключаемое**. Не спам — сервис.

## 2. Бизнес-логика (жёстко, без вариаций)

Напоминание показывается, только когда выполнены **ОБА** условия:

1. С последней успешной чистки прошло **≥ 30 дней** (таймстамп чистки храним в SharedPreferences).
2. Текущий скан показывает мусор **> 500 МБ** (порог — константа в коде, название `kReminderJunkThresholdMb`). Мусора нет — молчим.

Если пользователь проигнорировал уведомление — следующее не раньше чем через 30 дней. Никаких snooze/повторов/эскалаций.

Частота итоговая: ≤ 12 уведомлений в год.

## 3. Техническая схема

| Компонент | Решение |
|---|---|
| Планировщик | `workmanager`: периодическая задача раз в сутки (тихая проверка условий). **Exact alarms НЕ нужны** (inexact periodic, никаких SCHEDULE_EXACT_ALARM). |
| Уведомления | `flutter_local_notifications`, отдельный канал `reminders` со стандартным звуком (никаких кастомных мелодий). Tap по уведомлению → открыть приложение на главном экране (для чистки). |
| Хранение | Только SharedPreferences (по AI_RULES): `last_clean_timestamp`, `reminders_enabled`. |
| Сервис | `ReminderService extends ValueNotifier` — синглтон, по архитектурным правилам. Вся логика в сервисе, экраны — только UI. |
| Тоггл | В `settings_screen.dart`: «Напоминания о чистке» вкл/выкл → `reminders_enabled`. По умолчанию ВКЛ. |
| Разрешение | `POST_NOTIFICATIONS` (Android 13+) запрашиваем **НЕ при старте приложения**, а сразу после первой успешной чистки — с нашим in-app диалогом (объяснение → кнопка). Если отказал — НЕ дёргаем повторно, тоггл в настройках остаётся, при включении — объясняем как включить в системе. |
| Кто дёргает permission | Существующая `requestNotificationPermission()` — подключить, не дублировать. |

## 4. Тексты (12 локалей, золотой l10n-паттерн, тон «ты»)

Скелет (RU — эталон, остальные 11 — переводы от RU):

- Диалог после первой чистки: «Порядок! 👍 Можем напоминать раз в месяц почистить телефон?» → «Напоминать» / «Не надо»
- Уведомление (title): «Пора почистить телефон»
- Уведомление (body): «Прошёл месяц с последней чистки. Найдено {size} лишнего — справимся за пару минут.» (size — локализованный размер из скана; если сложно подставлять — статичный текст «Телефон снова захламился. Пара минут — и порядок.», выбери проще, обоснуй в отчёте)
- Тоггл в настройках: «Напоминания о чистке» + подзаголовок «Раз в месяц, если накопился мусор»

Правила локализации — из `AI_RULES.md` §2: неформальное «ты» во всех языках, EdgeInsetsDirectional, без `const` у пересобираемых виджетов, single MaterialApp.
