# CLEANER «ИГРАЮЧИ» — игровой режим очистки (концепт, 28.11)

> Источник: идея Владимира + разбор с К3-Макс/К3-Game (28.11).
> Решение: DECISIONS 28.11 («Суд»/«Подстава» — стоп, это направление — к
> проработке). Статус: КОНЦЕПТ. Код продукта — после тестов C0/C1 и визы.

## Формула
«Очисти свой телефон играючи»: короткая одиночная сессия, файлы —
физические предметы на столе, пользователь сам решает судьбу каждого,
корзина наполняется, в конце — подтверждённая очистка и экран порядка.

## Визуальная грамматика (три правила)
1. **Мусорный вид с самого начала** = предположение Cleaner
   (подпись «Возможный мусор», никогда «безопасно удалить всё»):
   старые APK — смятые банки, временные файлы — комки бумаги,
   остатки установок — пустые коробки, известные кэши — обёртки.
2. **Превращение в мусор** = решение пользователя: отметил фото/видео/
   документ → объект смялся/сложился и упал в корзину; отмена —
   разворачивается обратно (видно, что выбор обратим).
3. **«Оставить» — тоже приятно**: объект аккуратно на полку с бликом,
   не серое «проигрышное» состояние. «Не знаю» — убирает со стола без
   наказания.

## Цикл сессии
Стол с предметами → разбор (перетащить в корзину / отметить / оставить /
не знаю) → счётчик «В корзине: N объектов, X МБ» обновляется после
каждого действия → стол разобран → «В корзине 14 объектов, 742 МБ»
→ [Посмотреть корзину · Очистить · Ещё раунд] → отдельное подтверждение
→ эффектный финал (пресс/измельчитель — только ПОСЛЕ подтверждения) →
экран порядка. До удаления пишем «В корзине», не «Освобождено».

## Запреты (красные линии)
- Награда ТОЛЬКО за разбор/порядок. НЕТ очков за: удалённые МБ,
  количество удалений, серии удалений, скорость решений.
- Режим — дополнительный, обычная очистка остаётся в один тап.
- Корзина обратима до финального подтверждения; предметы видны,
  любой можно вернуть.
- Приложение не знает ценность личного файла: пользователь — судья,
  Cleaner — конвейер. Формулировки: «Кандидат на очистку», «Похоже на
  дубликат» (при надёжном детекте), «Решение за вами».
- Без стриков, ежедневного давления, комбо, магазина, уровней.

## Эталоны
- Цикл: Swipewipe (свайп-разбор, обратимая корзина, финальное
  подтверждение). Органайзер-эталон: Slidebox. Почта: Cleanfox.
- Удовольствие: PowerWash Simulator, House Flipper, A Little to the Left.
- Связки «реальные файлы → предметы → корзина с МБ → раунд → очистка»
  на рынке не найдено (не доказательство отсутствия, но клона нет).

## Тесты до продукта
**C0 — игровое удовольствие (0 реальных файлов):** кликабельный
прототип, 5–10 вымышленных объектов, 3 действия (Оставить/В корзину/
Пропустить), сессия 60–90 сек, без баллов, без CTA. Мерим: понятно без
объяснений? хочет вторую сессию? что именно приятно? не сгребает ли
всё в корзину бездумно?
**C1 — реальная польза без реального удаления:** Cleaner показывает
реальных кандидатов, игровой разбор, корзина пересматривается,
ФИЗИЧЕСКОЕ УДАЛЕНИЕ ОТКЛЮЧЕНО. Мерим: помогает ли разобрать своё
хранилище, сохраняется ли доверие.
**Стоп-сигналы:** думает, что корзина уже удалела; гонится за объёмом;
верит классификации как истине; раздражается, что игра тормозит
обычную очистку; не хочет второй сессии на вымышленных файлах.
