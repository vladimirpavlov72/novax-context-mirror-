## Задача (desk-research, у тебя браузер — твоя стихия)

1. **Полка GP**: топ-5 файловых менеджеров по выдаче GP (RU + EN-запросы
   «file manager», «файловый менеджер» + рейтинги). Для каждого: модель
   монетизации (честно: где реклама, где подписка, где one-time), рейтинг,
   число установок, сильные/слабые стороны по публичным обзорам.
2. **Боли из отзывов** (регламент review-mining): минимум 30–50 реальных
   отзывов по топ-3 (GP-отзывы, Reddit, 4PDA). Топ-5 тем боли с частотами и
   дословными цитатами + ссылками. НИЧЕГО не выдумывать — цитата или тезиса
   нет.
3. **Карта стандарта категории**: какие экраны/потоки обязательны (домашняя
   папка, поиск, копирование, архивы, очистка?), сколько тапов до ключевых
   действий у топов. Выход — recon.md (черновик, руками дополним на A52).
4. **Наш тезис** (главный артефакт): 3–5 предложений — как позиционировать
   ПЛАТНЫЙ файловый менеджер против бесплатных гигантов. Честный оппонент-
   разбор: кому мы проигрываем наверняка и что с этим делать. Варианты
   углов: приватность без рекламы/трекинга, честная очистка (MES как у
   Cleaner), «купил раз — навсегда», SAF-полнота без костылей.
5. **features.csv**: фича | у кого есть | наша реакция (сделаем / иначе /
   не нужно — почему). Минимум 20 строк.
