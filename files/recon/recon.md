## 2. Стандарт категории (обязательные экраны/потоки)

Главная-категории (Загрузки/Фото/Видео/Аудио/Документы/APK) → навигатор папок
с путём → файловые операции мультивыбором → поиск → просмотр медиа → архивы →
анализ памяти (у CX — лицо приложения) → корзина → закладки → управление
приложениями. Облака/LAN/ПК — уровень «про», не массовый стандарт. Тапы до
ценности: CX — 1–2, Solid — 2–3, TC — 3–5 (проигрывает новичкам).

## 3. Наш тезис (главный артефакт)

**«Файловый менеджер, которому доверяешь память телефона»**: единственный на
полке с ЧЕСТНОЙ очисткой наследия Cleaner (показываем каждый файл перед
удалением, MES, без пугалок) + функционал CX-класса + модель «159 ₽ один раз
навсегда» — без рекламы, без трекеров, офлайн-first, без облаков по умолчанию.
Мы НЕ «бесплатная замена Files by Google» — мы платный инструмент для
обжёгшихся: кто видел трекеры у «бесплатных», кто не хочет платить Solid
снова за новую лицензию и докупать аддоны MiXplorer.

**Честный оппонент-разбор — кому проигрываем наверняка:**
1. Массовый «поставил и забыл» — ему хватает предустановленного Files by
   Google. Не наш покупатель, не гонимся.
2. Аудитория open-source (Fossify бесплатен) — не наша цена честности.
3. Про-пользователи (root/LAN/облака) — уходят к Solid/MiXplorer/X-plore.
   v1 их не берём сознательно.
**Кому выигрываем:** «осознанный хозяин телефона» — тот же человек, что
покупает Cleaner: боли одинаковые (память, порядок, доверие). Кросс-продажа
внутри линейки (бренд-полка) — дешёвый канал, которого нет ни у кого на полке.

**Вердикт: стоит делать — с условиями.** Условия: ① не гнаться за «про»
фичами (облака/LAN/root — НЕТ в v1, это другая цена и другой INTERNET);
② очистка-наследие = главный герой карточки (наш несопоставимый дифф);
③ Files идёт ПОСЛЕ обкатки витрин (триггер конвейера 18.10 не отменяется).
