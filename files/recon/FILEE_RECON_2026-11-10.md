## 1. Filee (github.com/KnifeLemon/Filee) — разбор репо

### 1.1 Витальные признаки (GitHub API, 2026-11-10)
- **25 283★** (заявлено 25 280 — подтверждаю), **1 450 форков**, 123 открытых issue, репо создан **2026-09-29** → ~6 недель жизни. Взрывной рост, топ-1 C# на Trendshift (день и неделя).
- **Стек:** C# / .NET 10 / Avalonia (desktop). Windows 10/11, Linux x64/ARM64, macOS preview (не нотаризован).
- **Лицензия:** MIT, © 2026 Myeonggu Kim (KnifeLemon) + контрибьюторы. Форки разрешены (`allow_forking: true`), ограничений нет — но bundled third-party компоненты под своими лицензиями (THIRD-PARTY-NOTICES). Код нам **не нужен** (стек другой), идеологию брать можно свободно.
- **Конвертаций описано:** в описании репо 263 формата, в README свежем — 270 (форматы пишутся). Без внешних движков ~половина; опциональные движки: ImageMagick, FFmpeg, LibreOffice, Pandoc, Ghostscript, calibre, Tesseract OCR, Upscayl.

### 1.2 Механика подачи (UX-фишка «пончик»)
- Держишь **Ctrl (Option на macOS) + тянешь файл** → у курсора открывается **«пончик» (donut) форматов**, отфильтрованный под тип перетаскиваемых файлов → дроп на сектор = конвертация. Результат сохраняется рядом с оригиналом. Прогресс — кольцо вокруг пончика.
- **Двусторонний пончик:** Tab / колесо мыши переворачивает на «обратную сторону» — до 12 вторичных секторов (обрезка, поворот, сжатие PDF и т.п.).
- Входы: drag-жест из любого файлового менеджера и даже **из браузера** (картинка/ссылка из Chrome/Firefox/Safari), правый клик в Explorer, горячая клавиша, дроп-зона на Home, CLI (`filee convert`, `filee watch`).
- **Watch folders** — авто-конвертация всего, что попало в папку (с сохранением подпапок).
- Группы секторов (до 6 пресетов веером), профили тулбаров по типам файлов, кастомизация drag&drop, светлая/тёмная темы, акцентный цвет.
- Идеология: «не открывать окно приложения вообще» — конвертер приходит туда, где пользователь уже работает. Это и есть главная вирусная фишка (демо 27 сек на filee.sh).

### 1.3 Архитектура (по docs/README, без клонирования)
- Модульная система «движков» (Settings → Engines): ядро на .NET + SkiaSharp/ImageMagick и пр., опциональные движки скачиваются по требованию из закреплённых `engines.json`. Цепочки маршрутов автоматические (HWP → HWPX → DOCX).
- CLI переиспользует те же движки и пресеты; `--json` для скриптов.
- Приватность как фича: ноль телеметрии, сеть — только проверка обновлений через GitHub API и докачка движков/OCR-языков (можно отключить). Подпись релизов с 2.4.0 (проверка подписи чексумм), Mark-of-the-Web сохраняется, жёсткие анти-злоупотребления (битые PDF, zip-бомбы, макросы).
- Security-культура высокая: два advisory исправлены в 2.4.0, активный баг-фикс релизами ~еженедельно (1.10 → 2.4 за ~6 недель).

### 1.4 Локали
- README перечисляет 19 языков приложения: English, Español, 日本語， 한국어, 简体中文， 繁體中文， Polski, हिन्दी, **Русский**, العربية (RTL), Português (BR), Français, नेपाली, ไทย, Türkçe, Português (PT), Deutsch, Italiano, Bahasa Indonesia, Tiếng Việt.
- В 2.4.0 добавились **бенгальский** и **персидский**; в 2.3.0 — итальянский, индонезийский, вьетнамский. RTL поддержан (арабский). **Русский есть**, README переведён на русский.
- Вывод: локализация комьюнити- driven (Adding-a-language.md), быстрое покрытие длинного хвоста.

### 1.5 Монетизация автора
- **Нет.** Приложение полностью бесплатное, «free and stays free». Только донаты: **GitHub Sponsors, Patreon, Ko-fi, PayPal, Fairy** (корейский, принимает местные карты). Спонсоры перечислены в About странице приложения. Microsoft Store / WinGet — как каналы дистрибуции, не монетизации.
- Доход автора = добровольные взносы, т.е. модель не масштабируется, но и не отравляет продукт рекламой/подписками — ключ к виральности.

### 1.6 Что позаимствовать идеологически (НЕ код)
1. **Конвертер поверх контекста пользователя**, а не «ещё одно окно». На Android это транслируется в: share-sheet любого приложения, контекстное меню файлового менеджера, виджет/шорткат, «конвертировать» прямо из Files.
2. **Пончик/радиальный выбор формата** — на тач-экране естественный жест (long-press → radial menu). В Flutter реализуемо (CustomPainter + GestureDetector), стоит попробовать как фирменный UX.
3. **Приватность как маркетинг:** «ноль загрузок, ноль телеметрии» — рабочий оффер против мусорных GP-конвертеров с серверами.
4. **Модульные движки по требованию**: ядро маленькое, тяжёлые кодеки (FFmpeg) — опциональная докачка. Снижает вес APK и порог входа.
5. **Watch folders → на Android: авто-конвертация в фоне** (WorkManager/foreground service) — «папка Inbox → всё в PDF».
6. **Длинный хвост форматов через опциональные модули** + CLI/JSON для power users.
7. **Скорость итераций:** еженедельные релизы, «Request a format» (GitHub-форма из приложения) — комьюнити как движитель роста.

## 2. Аналоги в сторах

### 2.1 Google Play (Android)
- **File Converter (Ice Cold Apps и клоны)** — самый известный all-in-one; **конвертация на сервере** (загрузка до ~100 МБ), бесплатно с рекламой, есть IAP. Главный объект ненависти аудитории: «cluttered, ad-heavy, oddly priced, built around uploading».
- **All File Converter** — тоже серверная загрузка (файлы удаляют через 24 ч), бесплатно.
- **Batch Image Converter** — локальная, реклама + IAP (снятие рекламы, больше файлов в батче).
- **VidCompact / Video Compressor** — видео/аудио, подписка/IAP, 3-дневный триал.
- **ZenConverter (github.com/Jasonzhu1207, свежий OSS, Kotlin/Compose)** — **локальный, без рекламы и аккаунтов**, FFmpeg, изображения/видео/аудио/PDF/шрифты/субтитры, AI-апскейл Real-ESRGAN и интерполяция RIFE через NCNN+Vulkan. Прямой идеологический наследник Filee на Android; пока узкий набор маршрутов, ранний статус. **Главный будущий конкурент в нише «офлайн на Android».**
- **Итог по GP:** нише топчется: либо серверная загрузка + реклама, либо узкие платные конвертеры. Полноценного all-in-one офлайн-конвертера уровня Filee **нет** — ZenConverter только начал.

### 2.2 RuStore
- Отдельной категории «конвертер файлов» фактически нет. Конвертация встречается как встроенная фича файловых менеджеров (SHAREit: «встроенный конвертер PDF и изображений»), плюс узкие приложения («Видео в MP3 конвертер», «PDF Converter Creator-Edit», «Pdf Converter Lite»). Свободное окно шире, чем в GP, но RuStore у нас заморожен — фиксируем как факт, не планируем.

### 2.3 App Store / Mac App Store
- **Convertible (getconvertible.app)** — образцовая монетизация нашего канона: **one-time $9.99**, free tier (безлимитные изображения + пресеты сжатия), Pro открывает видео/аудио/PDF/батч. 100% локально, без телеметрии, интеграция в Finder Quick Actions/Shortcuts, menu bar. Ниша «Mac-локальный конвертер» уже занята сильным игроком.
- **Permute ($15+, подписка/разовая), HandBrake (бесплатно OSS), CloudConvert/FreeConvert (онлайн, подписка)**, браузерные WASM (VERT, VisualConvert — freemium веб).
- **FileHop (Mac/Win, free)** и **CamoConvert ($19 one-time, Win/Mac)** — офлайн с приватностью, стрип метаданных, CLI.
- **Десктоп:** Filee выжег десктопный сегмент OSS за 6 недель; платные десктоп-конвертеры (reaConverter, Convertify) живут на B2B/нишевых.

### 2.4 Чем продают офлайн-конвертеры без загрузок
1. **Приватность/безопасность** («файл не уходит с устройства», предупреждения FBI про онлайн-конвертеры — реальный маркетинговый актив).
2. **Скорость** (нет аплоада, аппаратное кодирование).
3. **Оффлайн-доступность** (самолёт, «глухие» зоны, air-gapped).
4. **Работа с чувствительными документами** (юристы, медики, журналисты).
5. **One-time purchase** как анти-подписочный жест — Convertible и CamoConvert прямо ставят «No subscription» в заголовок.

### 2.5 Окно в нише
- **Десктоп (Win/Mac/Linux): окно закрыто** Filee (бесплатный, MIT, виральный) + донат-модель. Входить платным десктоп-конвертером сейчас = биться с бесплатным 25k★.
- **Android: окно открыто.** В GP нет all-in-one офлайн-конвертера без рекламы/серверов; ZenConverter — единственный OSS-претендент, ещё узкий и молодой. Спрос подтверждён виральностью Filee (25k★ за 6 недель — это голос за механику и офлайн-идеологию).
- **iOS/Mac: окно узкое** (Convertible сильный), нам не фокус.

## 3. Рекомендация: отдельное приложение vs фича в Files

### Вариант A. Отдельное приложение «NOVAX Конвертер» (Flutter/Dart, Android, GP, one-time $0.99–2.99)
**Плюсы:**
- Отдельная ASO-витрина: запросы «file converter», «конвертер файлов», «HEIC to JPG», «video to MP3» — огромный поисковый спрос, у Files его нет. Новый продукт = новая выдача, новые установки, кросс-промо с Files.
- Чистое позиционирование: «офлайн-конвертер без загрузок и рекламы» — контраст с мусорными серверными аналогами; идеально ложится на канон NOVAX.
- Независимый релизный цикл и цена ($0.99–2.99 — импульсная покупка, конверсия выше, чем у файлового менеджера).
- Свобода UI: радиальный «пончик» форматов как фирменная фишка — в Files он чужероден, здесь он и есть продукт.
- Фича может «перерасти» в продукт: share-target, виджет, быстрый доступ из любого приложения.
**Минусы:**
- Нужен новый листинг, отзывы, накопление рейтинга с нуля.
- Дублирование инфраструктуры (лицензирование, платежи, локализация — хотя это shared-контур NOVAX).
- Риск: часть пользователей Files ждёт конвертер бесплатно внутри — управляем ожиданиями в ченджлоге.

### Вариант B. Фича внутри Files (конверт из контекстного меню)
**Плюсы:**
- Мгновенная аудитория текущих покупателей Files → рост ценности существующего $2.99-продукта, аргумент для отзывов «приложение развивается».
- Тёплая точка входа: пользователь уже в файловом менеджере, файл под рукой — «поделиться → конвертировать» без нового приложения.
- Меньше поддержки: один продукт, одна кодовая база, общие платежи.
- Идеологически близко к Filee: конвертер поверх файлового контекста.
**Минусы:**
- Не даёт новых установок: ASO-запросы «converter» в листинг Files не приведут (GP не ранжирует менеджер файлов по «конвертер»).
- Размывает продукт: Files — менеджер; тяжёлые FFmpeg-манёвры и радиальные меню усложнят его.
- Ограниченная демонстрация фишки: контекстное меню слабее вирального «пончика» как самостоятельного продукта.
- Цену поднять сложно: фича внутри $2.99-аппа не монетизируется отдельно.

### Вердикт
**Двухшаговая стратегия: сначала фича в Files (MVP), затем отдельное приложение «NOVAX Конвертер».**

1. **Шаг 1 (быстрый, 2–4 недели):** внедрить базовый офлайн-конвертер прямо в Files — «Поделиться/Контекстное меню → Конвертировать» для топ-направлений: изображения (JPG/PNG/WEBP/HEIC/PDF), аудио из видео (MP3), видео сжатие (MP4), images→PDF, PDF merge/compress. Движки: чистый Dart для изображений/PDF (image, pdf пакеты) + опциональный FFmpeg-модуль (ffmpeg-kit или свой нативный слой) для медиа — по образцу модульной схемы Filee (ядро маленькое, движки по требованию). Это поднимает ценность Files и даёт полигон для обкатки UX.
2. **Шаг 2 (следующий релизный цикл):** отдельное приложение «NOVAX Конвертер» ($0.99–2.99, one-time, без рекламы/трекинга) с фирменным UX «пончика» на long-press, share-target из любого приложения, watch-папками через WorkManager, расширенной матрицей форматов. Из Files — кросс-промо.

**Аргументы за такой порядок:**
- Спрос и виральность механики доказаны Filee (25 283★ за 6 недель), но его движок — C#/Avalonia, desktop. Прямого форка под Flutter нет и быть не может — копировать придётся UX/идеологию, а не код. MIT это позволяет.
- На Android ниша пустая: крупные GP-конвертеры грузят файлы на серверы и мусорят рекламой. Оффлайн + one-time + без рекламы — честное окно, подтверждённое успехом Convertible ($9.99 one-time) на Mac.
- Отдельный листинг сразу — рискованно без проверенных движков и UX; фича в Files даёт обкатку на платной лояльной аудитории и усиливает существующий продукт.
- Важно успеть до того, как ZenConverter (или клон Filee под Android) займёт нишу — окно открыто сейчас, ZenConverter ещё узкий.
- RuStore не трогаем (заморожен), GP — главный рынок, что совпадает с фокусом.

**Риски и оговорки:**
- Объём «263 формата» на Flutter/Dart недостижим в одиночку — начинать с 15–20 маршрутов, покрывающих 90% запросов (HEIC→JPG, video→MP3, compress, images→PDF, PDF→images).
- Вес APK с FFmpeg — минимум +20–30 МБ; модульная докачка (feature delivery / отдельный скачиваемый модуль) по образцу engines Filee.
- GP-политика: декларировать приватность честно (нет permission INTERNET вообще — сильный маркетинговый ход, как у ZenConverter).
- Не копировать код Filee (MIT формально разрешает, но стек другой и код не переносим); заимствуем только идеи: радиальное меню, watch-папки, «request a format», модульные движки.
