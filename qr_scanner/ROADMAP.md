## v2.0.21 — Генерация QR-кодов

### Почему реально

| Аспект | Оценка |
|--------|--------|
| Техническая сложность | Низкая |
| Offline | ✅ Не нужен интернет |
| Permissions | ✅ Не нужны новые разрешения |
| Время разработки | 1–2 дня |
| pub.dev offline | `qr_flutter` можно закэшировать в `~/dev/vendor/packages/` |

### Типы QR-кодов

| Тип | Назначение |
|-----|------------|
| URL | Поделиться ссылкой |
| Wi-Fi | Гость сканирует → автоподключение к сети |
| Контакт (vCard) | Цифровая визитка |
| Телефон | Позвонить по QR |
| Email | Написать письмо |
| SMS | Отправить сообщение |
| Текст | Любой произвольный текст |

### UI

```
┌─────────────────────────┐
│  📷 Сканировать QR      │  ← текущий экран сканера
│                         │
│  [+ Создать QR-код]     │  ← новая FAB-кнопка
│                         │
│  📜 История             │
└─────────────────────────┘
```

**Flow:**
1. Пользователь нажимает **«Создать QR-код»**
2. Выбирает тип QR-кода
3. Вводит данные (URL, SSID/пароль Wi-Fi, контакт и т.д.)
4. Видит превью QR-кода
5. Доступные действия: **Поделиться** / **Сохранить в галерею**

### Техническая реализация

```yaml
# pubspec.yaml
dependencies:
  qr_flutter: ^4.1.0  # offline из ~/dev/vendor/packages/
```

```dart
// Генерация QR:
QrImageView(
  data: 'https://novaxhub.ru',  // или любой текст/Wi-Fi конфиг/vCard
  version: QrVersions.auto,
  size: 200.0,
  backgroundColor: Colors.white,
  foregroundColor: Colors.black,
)
```

## Технические заметки

- **Генерация:** использовать `qr_flutter` (закэшировать в `~/dev/vendor/packages/`).
- **Архитектура:** сохранить текущий стек — `ValueNotifier`, `Navigator`, `SharedPreferences`, минимум зависимостей.
- **Локализация:** новые экраны и строки сразу на 12 языках.
- **Хранение:** созданные QR-коды можно сохранять в историю (отдельная вкладка или метка).
