## 0. Главные правила спринта (красные линии)

1. Ничто не блокирует релизы: v2.3.0 уже залит; метрика среды = бейзлайн.
2. Порядок: сверка метрики «просмотры» → витрины → фичеринг-пайплайн →
   GEO-поворот → RU-медиа (по событию) → ценовой тест 249 ₽ (после бейзлайна).
3. Дизайн-гейт обязателен: кадр-«пластина» → ревью Саши → клонирование.
4. Модель v2 (первая чистка бесплатно + 300 МБ/30 дн) НЕ трогаем до 3–4 недель
   бейзлайна; «150 МБ/7 дн» и прочие варианты — только через A/B позже.
5. Без публичных дедлайнов grandfathering (голос: давление = табу). Без цен/
   триала/рейтингов/настроек/диалогов разрешений на кадрах (GP-safe).
6. Накрутки, мотив-трафик — никогда. llms.txt не трогаем (ноль-стоимость);
   GEO-усилия = упоминания бренда + свежесть контента.

## 6. Контрольные точки

- **Каждую среду:** Ворк — METRICS_WEEKLY (с панелью A5).
- **Неделя +3–4 после заливки правленых карточек:** замер CVR по каждой.
  Цель: линейка 3–6% (ориентир-оценка; эталон Привычек+ 6,71%). Если CVR не
  двигается после полного ремонта — следующий подозреваемый источник трафика,
  не витрина (эскалация к К3-Макс).
- **Бейзлайн v2.3.0 (3–4 недели):** затем ценовой тест 159→249 ₽ на Cleaner
  (последовательный, 3–4 недели; контроль падения конверсии <15%, иначе откат).
- **Триггер конвейера приложений** (решение 18.10): конверсия растёт → газ;
  стоит → чиним воронку. NOVAX Files по прежнему плану (после обкатки витрин).
