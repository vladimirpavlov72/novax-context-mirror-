## Объём
1. На экране результата очистки — кнопка «Поделиться».
2. Генерация PNG 1080×1920: найдено N ГБ мусора (факт), было/стало
   свободно (факт), бренд, #ЦифроваяПомойка. Цифры — только реальные
   из результата, без округления «в красивую».
3. Шэринг через системный intent (картинка), без новых разрешений,
   без INTERNET-зависимости.
4. Локали RU/EN (строки через arb), остальные — волной.

## Приёмка
- на устройстве: кнопка → картинка → системный шэринг (TG/почта);
- цифры на картинке == цифрам результата;
- analyze 0, дым/тесты зелёные, Z-ревью 0 BLOCKER;
- другие сторы: фича общая (не GP-специфика) — включить по флейворам
  без конфликтов с текущими ветками.
