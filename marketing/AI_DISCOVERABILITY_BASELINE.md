## 3. Техническая проверка сайта

### 3.1 Доступность service-файлов

### 3.2 robots.txt

```
User-agent: *
Allow: /
Sitemap: https://novaxhub.ru/sitemap.xml
```

**Оценка:** базовый. Нет явного приглашения для ИИ-ботов (GPTBot, ClaudeBot, PerplexityBot, OAI-SearchBot, Google-Extended).

### 3.3 sitemap.xml

```xml
<?xml version="1.0" encoding="UTF-8"?>
<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
  <url>
    <loc>https://novaxhub.ru/</loc>
    <changefreq>weekly</changefreq>
    <priority>1.0</priority>
  </url>
</urlset>
```

**Оценка:** только главная страница. Нет якорей на приложения (`#app-cleaner`, `#app-qr` и т.д.).

### 3.4 llms.txt

Содержит:
- общее описание NOVAX;
- список приложений с ценами;
- 4 принципа;
- ссылки.

**Оценка:** хороший старт, но **нет раздела «Если вы ищете...»** с привязкой интентов к приложениям.

### 3.5 JSON-LD / Schema.org

HTML содержит 4 блока `<script type="application/ld+json">`:
- `WebSite` — название, URL, описание, язык, ссылка на publisher.
- `Organization` — NOVAX, URL, описание, Telegram.
- `ItemList` — 4 `MobileApplication` (Cleaner, QR, H₂O, Habits+) с `operatingSystem`, `applicationCategory`, `offers`.
- `FAQPage` — 4 вопроса про цену, скачивание, данные, честные приложения.

**Текущие name в JSON-LD:**
- Cleaner — очистка телефона
- NOVAX QR — сканер QR-кодов
- H₂O — контроль воды
- Habits+ — трекер привычек ← нужно исправить на «Привычки +»

**Оценка:** разметка присутствует, но требует усиления:
- добавить `description` с problem-фразами;
- добавить `featureList`;
- исправить `name` у Habits+ → «Привычки +»;
- добавить `url` с якорем на каждое приложение.

### 3.6 Индексация

Проверка `site:novaxhub.ru` через поисковый инструмент **не удалась** (ошибка 500 сервиса). Требуется ручная проверка в Google/Yandex.

### 3.7 Внешние упоминания NOVAX / novaxhub.ru

Поиск `"novaxhub.ru" OR "NOVAX" приложение` показал **только нерелевантные результаты**:
- GitHub `artwalker/Novax` — операционная система Novax OS.
- GitHub `novax-dev/novax-contract` — блокчейн-контракт.
- Сільпо — хозтовары Novax (салфетки).
- Postroil — краска NOVAX.

**Релевантных упоминаний мобильных приложений NOVAX в интернете нет.** Это подтверждает, что основной упор должен быть на real-time поиск / RAG через оптимизацию собственного сайта.

## 4. Проблемы, выявленные на старте

1. **Сайт не ранжируется по ключевым интентам** — NOVAX отсутствует в выдаче по всем 12 тестовым запросам.
2. **Контент feature-ориентирован**, а не problem-ориентирован. Нет фраз вроде «мало памяти → Cleaner», «забываю пить воду → H₂O».
3. **`llms.txt` без интент-раздела** — ИИ не получит быстрой карты «проблема → решение».
4. **JSON-LD слабый** — нет описаний проблем и списка функций.
5. **`robots.txt` базовый** — нет явного приглашения ИИ-ботов.
6. **`sitemap.xml` бедный** — нет якорей на приложения.
7. **Нет внешних сигналов** — обзоров, упоминаний, отзывов с ключевыми словами.
