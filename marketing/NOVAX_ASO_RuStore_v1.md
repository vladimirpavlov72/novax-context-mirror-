# NOVAX — ASO-пакет для RuStore (v1.1, 26.07.2026)

Общий тон бренда NOVAX: честная цена, без рекламы, без подписок, данные не покидают устройство. Не обещаем того, чего приложение не делает (честный cleaner, честный scanner).
