# Шаблоны ответов на отзывы — альт-сторы (Samsung/Huawei), Cleaner

> Тема 4, Действие 3. Языки: RU/EN/AR/ES. Голос: voice.md — на «ты», без
> шаблонного «спасибо за отзыв» без содержания, негатив = признание + действие.
> Правила: отвечать в течение 24–48 ч (Владимир, 2 раза в неделю), имя
> пользователя подставлять из карточки отзыва. Вставки — [в квадратных скобках].
> Контекст: v1 полностью бесплатна — жалоб «почему платно» не будет,
> но будет «как это бесплатно?» — на него честный ответ ниже.

## RU

**П1 (5★ без текста):**
```
Спасибо! Рады, что Cleaner пригодился. Если будет чего не хватать — напиши, читаем всё.
```

**П2 (хвалит конкретное):**
```
Спасибо! [Фича из отзыва] — наша любимая часть приложения. И напомним: без рекламы и подписок, так и останется.
```

**Н1 (баг/краш):**
```
Привет! Обидно, что столкнулся с этим. Напиши, пожалуйста, модель телефона и на каком шаге произошло — разберёмся и починим в ближайшем обновлении. Баги чиним в первую очередь.
```

**Н2 («недочистил» / не нашёл мусор):**
```
Понял тебя. Скажи, пожалуйста, что искал — например, кэш конкретного приложения или большие файлы? Сканер показывает только то, что безопасно удалять, иногда цифра скромнее ожиданий. Расскажи подробнее — улучшим.
```

**Н3 («как это бесплатно? в чём подвох»):**
```
Честный ответ: подвоха нет. Мы независимая студия, эта версия для альт-сторов — без пейвола принципиально. Развиваемся за счёт честной модели на других площадках. Рекламы и сбора данных не будет — это наш фундамент.
```
