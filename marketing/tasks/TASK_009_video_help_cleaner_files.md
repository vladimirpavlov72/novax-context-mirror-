## 4. Видео Cleaner

### Сценарий
1. Открыть Cleaner.
2. Запустить анализ хранилища.
3. Показать категории и занимаемый объём.
4. Открыть группу и показать конкретные файлы.
5. Выбрать безопасные тестовые файлы.
6. Подтвердить удаление.
7. Показать фактический результат очистки.

### Смысловой акцент
Пользователь должен понять не только куда нажимать, но и что:
- перед удалением можно посмотреть файлы;
- выбор остаётся под его контролем;
- приложение сначала анализирует, затем очищает.

### Запрещённые обещания
- «Ускорит телефон».
- «Освободит гарантированно N ГБ».
- «Полностью безопасно удалит всё ненужное».
- Автоочистка, виджет и другие отсутствующие функции.

## 8. Помощь внутри приложений

### Офлайн-слой
В разделе «Помощь» — инструкция из 3–5 коротких шагов. Требования:
- доступна без интернета;
- не появляется принудительно при каждом запуске;
- не блокирует основной сценарий;
- использует текущие названия кнопок и экранов;
- не требует обновления видео при изменении текста.

Для Files дополнительно — контекстные подсказки возле MES/SAF: какой доступ запрашивается; зачем; что сможет приложение; как отозвать.

### Видео-слой
Пункт «Посмотреть видеоинструкцию»:
- открывается только по тапу; рядом обозначено «онлайн»;
- ведёт на YouTube или VK Видео;
- не открывается автоматически;
- при отсутствии интернета офлайн-инструкция доступна;
- пустая или заглушечная ссылка в релиз не допускается.

Видео в APK не включать.

## 9. Порядок выполнения

### Этап 1 — Cleaner (СТАРТ: после закрытия витринной волны H₂O/QR)
1. Маркетинг передаёт сценарий Гие.
2. Гиа подтверждает сборку и фактичность шагов.
3. Р-3 снимает экран.
4. Монтажёр собирает ролик и обложку.
5. К3 проверяет финальный MP4.
6. Владимир проходит пользовательский тест.
7. После успешного теста Владимир публикует.

### Этап 2 — NOVAX Files (после стабилизации UI этапа 4)

2. Р-4 подтверждает сценарий MES/SAF.
3. Далее — тот же цикл, что для Cleaner.
4. Если UI продолжает меняться, этап остаётся в `DRAFT`.

### Этап 3 — помощь в приложениях
1. Маркетинг передаёт короткие тексты.
2. Р-2 и Р-4 реализуют каждый в своём приложении.
3. Z проверяет изменения.
4. Проверить офлайн-режим и переход по видеоссылке.
5. Релизить только с рабочей ссылкой либо временно без видео-пункта, но с готовой офлайн-помощью.
