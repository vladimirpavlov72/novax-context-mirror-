# ЯКОРЬ-КАНОН цены (B3) — единый источник правды

> Канон из решения 09.10, зафиксирован в спринте (Б3). Применять во всех
> карточках и пейволах. Формат с зачёркиванием — исключение из бренд-правила
> «без зачёркнутых цен»: зачёркивается не «наша фейковая старая цена», а
> рыночный якорь подписной модели, с которой сравниваем наше предложение.

## RU (RuStore, карточки и пейволы)

```
Подписка на год: ~~1 990 ₽~~ → Разово: 159 ₽
```

## EN (Google Play, мир $)

```
Subscription: ~~$29.99/yr~~ → One-time: $2.99
```

## Что заменено

- QR: фейковая «~~799 ₽~~ (старая цена)» — ОТМЕНЕНА (решение 09.10). В живых
  текстах её нет (grep чистый); в archive/qr_RUSTORE_ASO_COMPLETE.md оставлена
  как история с пометкой.
- Все новые тексты берут якорь ТОЛЬКО отсюда, не выдумывают числа.
