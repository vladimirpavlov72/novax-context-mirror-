# Шаблон задания для Ромы-маркетинга (Kimi Code)

Как пользоваться:
1. К3 готовит задание по этому шаблону, один файл = одно задание.
2. Файл кладётся в `marketing/tasks/` с именем `TASK_001_краткое_название.md`, нумерация сквозная.
3. Владимир сохраняет файл в репо, Рома-маркетинг читает и выполняет.
4. Если задание ссылается на контекст, которого нет в разделе 2, — Рома-маркетинг не гадает, а спрашивает Гиа, какие файлы читать (он знает полный контекст проекта).
5. Готово → commit + push + короткий отчёт Владимиру → Владимир кидает итог К3 на ревью.
