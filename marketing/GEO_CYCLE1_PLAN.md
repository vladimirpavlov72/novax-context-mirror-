> Утверждён Владимиром 26.10. Заменяет GEO_CYCLE1_PLAN v1.0 (гейт К3
> пройден, но Владимир упростил цикл: измерения не должны превышать
> ценность эксперимента). Сначала доказываем воспроизводимость одного

## 1. Главные рамки

- P0 — релизы, стабильность, витрины и консоли. GEO не крадёт их время.
- WIP — один формат: QR.
- Публичная версия цикла — QR 2.1.0+2027.
- Если выходит новая публичная версия, релиз не останавливается.
  Наблюдения до/после не смешиваем; смену версии отмечаем в confounders.
- Claims соответствуют публичному билду, а не master.
- Смена дат без новых фактов запрещена.
- Нет данных — нормальный результат, а не повод расширять работы.

## 3. КОНТУР А — маленькое наблюдение

### A0. Заморозка промптов
До прогона Гиа фиксирует два QR-промпта: 1) discovery с ограничениями;
2) brand verification. После просмотра ответов формулировки не меняем;
новая версия — отдельно, без смешивания.

### A1. Пилот 16 ответов
**Исполнитель:** Ворк, ассист Гиа. **Формула:** 2 промпта × 4 движка
(ChatGPT, Gemini, Яндекс/Нейро, Perplexity) × 2 повтора. **Потолок:**
0,5 ИИ-дня. Сохранить: полный текст, URL, движок и режим поиска, mention/
recommendation, фактические ошибки, конкурентов, время получения/разметки/
КК. Скриншоты — только рекомендация NOVAX / фактическая ошибка / install
card / аудит-выборка.

### A2. Мини-source-gap
**Исполнитель:** Гиа/Ворк. **Потолок:** вместе с A1 ≤ 1 ИИ-дня. По тем же
16 ответам: shortlist, использованные источники, какого факта NOVAX не
хватает, какие площадки подходят для приглашения. Новые прогоны ради
«полноты» не добавлять; площадок меньше пяти — не добирать.

### A3. Техническая гигиена
**Исполнитель:** Рома-2. **Потолок:** 0,5 ИИ-дня. robots/WAF, HTTP 200,
доступность HTML ботам. В потолок — только снятие явно ошибочных
блокировок; перестройка — отдельная эскалация Гиа.

## 4. КОНТУР Б — QR-доказательный пилот

### B1. Claims registry QR
**Исполнитель:** маркетинг, фактчек Ромы-2. **Потолок:** 1 ИИ-день.
5–8 утверждений (факт, способ проверки, ограничение, версия, канонический
URL, короткая формулировка). Результат: `marketing/research/claims_qr.md`.

### B2. QR Evidence Kit
**Исполнитель:** Галилео. **Потолок:** 1 ИИ-день. Один короткий комплект
на 3–5 сценариев, прохождение ≈ до 20 минут, понятен без устных подсказок.
Права проверяющего фиксируются заранее: менять методику, добавлять
неудобные сценарии, публиковать любой результат без согласования.
Два воспроизведения — НЕ DoD изготовления kit. Задание:
`marketing/tasks/TASK_007_QR_evidence_kit.md`.

### B3. Страница «кому QR NOVAX не подходит»
**Исполнитель:** маркетинг, публикация сайт-контура. **Потолок:** 0,5
ИИ-дня. DoD: HTTP 200; без авторизации; canonical; внутренняя ссылка;
sitemap/llms.txt; соответствие claims registry. Индексация — наблюдение,
не условие приёмки.

### B4. До пяти персональных приглашений
**Подготовка:** маркетинг (0,5 ИИ-дня). **Отправка:** Владимир, ≤ 20 мин.
Приоритет — площадки из мини-source-gap; если нет — Гиа может разрешить
опытных Android-пользователей. Не покупать участие/публикацию/отзыв.
Цель цикла — два самостоятельных воспроизведения без подсказок (цель, не
гарантированный DoD рассылки).

## 5. День 14 — решение без самообмана

Оцениваем: сколько ответов/внешних результатов получено; понятен ли kit
без подсказок; сколько людей завершили воспроизведение; какие дефекты
найдены; точность claims и AI-ответов. НЕ оцениваем: монетизацию, рост
Recommendation Rate, причинный вклад GEO, «победу по цитатам».
Решения: исправить kit один раз / stop-investment (активы остаются) /
разрешить следующий узкий шаг. Отложенный контроль T+30/45 — только по
решения Гиа.

## 7. Предохранители методолога (Галилео, приняты Гиа 26.10 — учитывать при исполнении и разборе)

1. **16 ответов = снимок, не baseline.** Мини-source-gap содержит наблюдения и
   гипотезы, не причинные выводы («не рекомендуют из-за X» — запрещено;
   можно: «назвали A и B, показали URL C, факт D исказили»).
2. **Статусы приглашений на дне 14**: не отправлено / нет ответа / отказ /
   согласился-не-начал / начал-не-завершил / завершил-с-подсказкой /
   самостоятельно воспроизвёл / изменил методику-с-результатом. Ноль ответов
   = нет данных о качестве kit (только о доступности проверяющих); двое
   застряли в одном месте = сильный сигнал о методике/продукте.
3. **Внутренняя приёмка ≠ внешнее воспроизведение.** Внутренняя отвечает
   «можно ли отдать постороннему?»; два внешних — «работает ли контур вне
   команды?». Смешивать запрещено.
