## Примечания для съёмки (Р-3 / монтажёр)

1. **Тестовые данные:** снимать на безопасных файлах (папка с тестовыми
   картинками/документами), без личных фото, имён, уведомлений, аккаунтов.
   Свайп шторки перед записью.
2. **Русский UI:** съёмка на сборке с TASK_010 (переводы влиты, HEAD f065611).
   Кнопки на экране: «Сканировать», «Изображения», «Папки», «В корзину»,
   «Очистить корзину», «Удалить навсегда?», «Журнал операций», «Выбрать папку».
3. **Экран доступа:** системное окно разрешения показывается один раз
   (первый запуск). Если на устройстве уже выдано — снять rationale-экран
   «Зачем нужен доступ» + карточку «Полный доступ включён».
4. **Цифры сводки** («12 061 файл · 115,4 ГБ») зависят от тестового
   устройства — снимать реальные, не накладывать графику.
5. **Панель действий** при выборе 5 файлов показывает: Копировать /
   Переместить / В корзину (Переименовать / Поделиться — при выборе одного).
6. **Озвучка:** спокойная, без пафоса. Титры короткие — по 2–5 слов.
7. **Не показывать:** пейвол/покупки, бренд-полку, системные уведомления,
   реальные пользовательские данные.
