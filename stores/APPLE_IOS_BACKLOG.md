# Apple iOS / App Store — бэклог-трек (НЕ стартуем)

> Статус: наблюдение. Решение Гиа 14.10.2026 после новости о xtool.
> Триггер для пересмотра: выполнение ≥3 критериев из списка ниже.

## Почему не сейчас
- **xtool** (github.com/xtool-org/xtool, 10.2k★, тренд 10.2026): собирает/подписывает/
  ставит на устройство iOS-приложения из SwiftPM на Windows/Linux, НО:
  1. App Store Connect deploy — НЕ поддерживается (по словам автора, в roadmap).
  2. Только SwiftPM/SwiftUI — Flutter-приложения NOVAX не переносит (нужна
     полная нативная переработка, месяцы на приложение).
  3. Требует Xcode.xip от Apple (лицензионная серая зона), нет asset catalogs/
     extensions/нормального дебага.
- Apple Developer: $99/год; санкционная чувствительность Apple к резидентам РФ
  выше Google — регистрация только через наш грузинский контур и с отдельным
  исследованием комплаенса.
- Стратегический фокус 2026–2027: Google Play (декабрь 2026) → RuStore/alt-сторы.

## Критерии «когда брать» (пересмотр трека)
- [ ] xtool или аналог умеет публиковать в App Store Connect (проверять quarterly).
- [ ] Ресурс: 1 новое приложение на SwiftUI (НЕ порт существующих), MVP ≤ 4 недель.
- [ ] Грузинский контур готов принять Apple Developer-аккаунт ($99/год, DUNS
      уже будет), изучен Apple-комплаенс для ИП Грузии с владельцем-резидентом РФ.
- [ ] Есть тестовое iOS-устройство (iPhone 11 mini у Ивана/Оли — кандидат).
- [ ] GP-запуск прошёл, приложения живут, появилась маржа на второй стор.

## Заметки
- iOS-аудитория платежеспособнее: $2.99 one-time на iOS — норм.
- Первый кандидат-приложение для iOS (если трек откроется): простой трекер
  привычек или H₂O — минимум платформенной специфики.
