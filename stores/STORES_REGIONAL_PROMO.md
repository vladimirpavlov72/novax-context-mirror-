- **Рабочие механики без бюджета (по открытым ASO-источникам 2026):**
  поиск внутри стора даёт порядка 65–70% органических установок; название —
  самый тяжёлый ранжирующий сигнал; первые 2–3 скрина несут вес конверсии;
  из поведенческих сигналов сильнее всего скорость установок и свежесть
  отзывов; регулярные обновления — положительный сигнал. Точные веса
  алгоритмов AppGallery/Galaxy Store не публичны — не выдумывать, сверять
  по факту заливки.

## 3. Три действия «максимум за минимум» (первые 2 месяца после выкладки Cleaner)

### Действие 1. ASO-пакет под регионы (недели 0–4, Рома-маркетинг, ~0 ₽)
Расширение TASK_004, по каждому приложению и стору:
- Волна 0 (запуск): карточки RU + EN полностью.
- Волна 1 (недели 2–4): AR, ES, PT, TR, DE, FR. Название Huawei — с поисковым
  хвостом. Ключи — не перевод, а рыночные формулировки (база — готовые
  keywords из RUSTORE_ASO_COMPLETE.md каждого приложения, адаптация под
  бесплатную v1).
- DoD: CONSOLE_PASTE-файлы по сторам и локалям (паттерн TASK_003).

### Действие 2. Петля внешних ссылок + запусковый всплеск (недели 1–2, далее по событиям)
Цель: всплеск установок первых 7–14 дней = сигнал скорости алгоритмам сторов.
- **Лендинги:** бейджи «Доступно в AppGallery / Galaxy Store» на 13
  интент-страницах novaxhub.ru (очистка → Cleaner и т.д.) — внешние ссылки
  на карточки + GEO-сигнал ИИ-поисковикам.
- **TG/MAX анонс запуска** (рубрика «Релизы и новости») с честным крючком
  grandfathering: «Первые пользователи AppGallery получают полную версию
  навсегда бесплатно — так решено и так будет». Без давления и дедлайнов
  (табу voice.md): механика сама создаёт мотив установить раньше. Гейт
  500/90 — внутренний, публично сроки не называем.
- **Скринкаст С1** (Cleaner, 45 сек, CONTENT_PLAN §5) со ссылкой на AppGallery.
- **4PDA:** один качественный пост в каталоге программ (RU-аудитория Android,
  пересекается с владельцами Huawei) — бесплатно, со скринами, без спама.
- Дзен-репост лучшего поста недели — только когда ритм ТГ стабилен 3–4 недели
  (CONTENT_PLAN §4).
- Повторить для Samsung-запуска (ноябрь). Не ставить анонсы в один день с
  GP-событиями декабря — координация через Гиа.

### Действие 3. Конвейер отзывов (недели 1–8)
- **Рома-2:** in-app промпт оценки после момента успеха (после чистки
  «минус N МБ», после создания QR) — 1 раз, без наград, текст по voice.md.
  Альт-сторы — своё окно; GP-флейвор остаётся на In-app Review API.
- **Рома-маркетинг:** шаблоны ответов на отзывы RU/EN/AR/ES по voice.md.
- **Владимир:** ответы на ВСЕ отзывы в консолях 2 раза в неделю (~10 мин).
- Отзывы = ранжирование + конверсия карточки + баг-радар.

**Бонус (не в счёт трёх, ~30 мин):** заявка на редакционное featuring в
AppGallery Connect / Galaxy Store после первых положительных отзывов.
Шанс низкий, цена — одна форма.

## 5. Метрики и контрольные точки
Аналитики в приложениях нет (офлайн-философия) — данные только из консолей.
- **Еженедельно (Владимир, 15 мин):** установки по сторам/странам, просмотры
  карточки → установки, число и средний рейтинг отзывов.
- **Недели 2–4 после первой заливки:** калибровка гейта 500/90 (DECISIONS 15.10).
- **Неделя 4:** разбор географии — страна вне плана с заметной долей
  установок → её локаль карточки в работу волной 2.
- **Неделя 8:** ретро — что сработало; решения по Дзену, featuring,
  расширению локалей.
