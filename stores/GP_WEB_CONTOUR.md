## Инфраструктура

1. **GitHub-организация** `novax-apps` (нейтральная, не личный аккаунт) —
   10 минут веб-интерфейса, руки Владимира (см. задачник).
2. Репозиторий `novax-apps.github.io` → GitHub Pages (бесплатный хостинг,
   HTTPS автоматом). Контент: статика (Hugo не нужен, чистый HTML).
3. DNS: в Cloudflare (домен там) — CNAME novaxhub.app → novax-apps.github.io.
   Владелец домена у Cloudflare = регистратор, всё делается в одной панели.
4. Зеркало контекста (novax-context-mirror-) НЕ трогаем — оно про контент
   для агентов, не про GP.
