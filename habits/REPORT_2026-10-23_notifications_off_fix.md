## 1. Корень бага (подтверждён кодом и QA)

`ServiceLocator.init()` безусловно перепланировал ВСЕ напоминания на каждом
запуске приложения, а состояние «выключено» нигде не персистилось:
`toggleNotifications(false)` делал только `cancelAll()` (in-memory флаг
сгорал, тумблер перечитывал системное разрешение и показывал «вкл»).
Сценарий жалобы: выключила → alarms отменены → открыла приложение →
init() перепланировал всё → уведомления вернулись.

## 2. Фикс (виза Ромы-2 23.10, включая обязательную прибавку)

- `StorageService`: персист-флаг `notifications_enabled_v1` (default true).
- `NotificationService.shouldScheduleReminders(appFlag, systemGranted)` —
  чистый гейт + `remindersAllowed()` для ВСЕХ точек планирования;
  platform-guard (Android-only API не читает «нет плагина» как «запрещено»
  на iOS/web). Отмена не гейтится — чистка всегда.
- `ServiceLocator.init()`: планирование только под гейтом;
  **реконсиляция**: системный запрет → флаг false + cancelAll().
- `SettingsViewModel`: off → persist false + cancelAll; on → persist true +
  reschedule; тумблер читает app-флаг.
- `AddHabitViewModel.save()`: планирование под гейтом.
- Тесты: `test/notifications_off_test.dart` 7/7; analyze 0 (flutter_gp 3.47.4).

## 4. 🔴 Находка QA: сиротские алармы вне кэша плагина (эскалация Роме-2)

`cancelAllNotifications` (vendored flutter_local_notifications 16.3.2,
`FlutterLocalNotificationsPlugin.java:1744`) отменяет будильники ТОЛЬКО по
своему кэшу `scheduled_notifications`: при пустом кэше — ранний возврат.

Факт на A52: после переустановки приложения в AlarmManager остались
будильники прошлой сессии (18:51/20:59, серии до 29.10) — вне кэша.
В `dumpsys alarm` записи остаются (призраки Samsung), но **не срабатывают**
(доказано B6: 12:46 после cancelAll не пришла). Текущих срабатываний
сирот в сессии не зафиксировано.

Риск: после потери кэша (очистка данных / сбой записи кэша) выключение
тумблером не отменит «чужие» будильники — это потенциальный хвост той же
жалобы (гипотеза №4 в TASK). Предложение: харднинг off-пути — после
cancelAll дополнительно `cancelHabitReminder` по полному id-пространству
всех привычек (кэш-независимая отмена по id). **Эскалация Роме-2** (паттерн
уведомлений — платформенный контур): решить в рамках D1-порта или отдельным
патчем. Не вносил сам — граница контура.
