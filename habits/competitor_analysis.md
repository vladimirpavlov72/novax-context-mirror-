# Анализ конкурентов: NOVAX Habits

**Дата:** 2026-07-31  
**Устройство:** Samsung A52 (1080×2400)  
**Конкуренты:** Loop Habit Tracker, Productive, Habit Tracker (Habit Genius)  
**Цель:** сравнить onboarding → главный экран → добавление привычки, выявить слабые места и точки дифференциации для NOVAX Habits.

---

## 1. Loop Habit Tracker (`org.isoron.uhabits`)

### Модель монетизации
Бесплатный, open-source, offline. Нет paywall, нет подписок, нет рекламы. Сильная позиция для пользователей, которые ценят приватность и минимализм.

### Onboarding
Очень короткий: 3 экрана-визитки + возможность пропустить.

![Loop onboarding](competitor_screenshots/loop_intro.png)

**Вывод для NOVAX:** Loop не «продаёт» приложение — оно просто показывает, что это трекер привычек. У NOVAX есть окно, чтобы за 2–3 экрана объяснить ценность: Streak Freeze + Weekly Challenge 5/7 + 30 дней trial.

### Главный экран
Максимально минималистичный: заголовок, недельная лента, пустое состояние с иконкой звезды.

![Loop главный экран](competitor_screenshots/loop_home.png)

**Плюсы:**
- Нет лишнего шума.
- Сразу понятно, куда жать, чтобы добавить привычку (`+`).
- Нет onboarding-попапов и «что нового».

**Минусы:**
- Пустое состояние не мотивирует и не объясняет первый шаг.
- Нет CTA-кнопки «Добавить первую привычку».
- Визуально аскетично — не вызывает эмоций.

### Добавление привычки
Открывается через `org.isoron.uhabits.activities.habits.edit.EditHabitActivity`.

![Loop добавление привычки](competitor_screenshots/loop_edit_habit.png)

**Поля:**
- Название
- Вопрос (для уведомлений и отметок)
- Цвет
- Частота (по умолчанию «Каждый день»)
- Напоминание (по умолчанию «Выкл»)
- Заметки

**Вывод для NOVAX:** форма простая и понятная. Мы можем сделать ещё короче: название, цвет, частота, время напоминания. Вопрос и заметки можно вынести в «Дополнительно».

## 2. Productive — Habit Tracker (`com.apalon.to.do.list`)

### Модель монетизации
Подписка: 2 790 ₽/год (53,51 ₽/неделю) или 279 ₽/неделю. Подписка через Google Play (в РФ заблокирована). Есть trial.

### Onboarding
Длинный, персонализированный flow:
1. Экран «Когда, если не сейчас?» + CTA.
2. Согласие на трекинг (GDPR-style) — приложение требует принять, иначе дальше не идёт.
3. Выбор времени пробуждения.
4. Выбор времени подведения итогов дня.
5. Paywall.
6. Вопросы о прокрастинации, концентрации, целях.

**Плюсы:**
- Сильная персонализация: пользователь сразу чувствует, что приложение подстроится под него.
- Визуальный стиль: иллюстрации, градиенты, фиолет/синий — близко к выбранной палитре NOVAX.
- Ясный paywall с ценами.

**Минусы:**
- Согласие на трекинг — дополнительный барьер. NOVAX этого избегает (no Firebase/no tracking).
- Paywall появляется рано, до того как пользователь увидел главный экран. Может отпугивать.
- Длинный onboarding (7+ шагов).
- Нет разовой покупки — только подписка.

**Вывод для NOVAX:**
- Можно заимствовать персонализацию (1–2 вопроса), но не перегружать.
- NOVAX выигрывает моделью: trial 30 дней → разовая покупка 159 ₽. Это проще и дешевле, чем подписка.
- NOVAX выигрывает отсутствием GDPR-консенса и трекинга.

## 3. Habit Tracker / Productive (Habit Genius, `com.habitgenius.habit.tracker`)

### Модель монетизации
Freemium / подписка (по аналогии с Productive). Приложение совмещает привычки, задачи, трекер настроения, финансы и дневник.

### Onboarding
Карусель «Изучить функции» из 5+ экранов. Каждый экран — цветной блок с функционалом.

![Habit Tracker onboarding 1](competitor_screenshots/habit_tracker_onboarding_2.png)

![Habit Tracker onboarding 2](competitor_screenshots/habit_tracker_onboarding_3.png)

![Habit Tracker onboarding 3](competitor_screenshots/habit_tracker_onboarding_4.png)

![Habit Tracker onboarding 4](competitor_screenshots/habit_tracker_onboarding_5.png)

**Плюсы:**
- Визуально ярко, понятно, что приложение умеет.
- «Пропустить» всегда доступна.

**Минусы:**
- Слишком много функций — пользователь теряет фокус.
- Привычки и задачи смешаны с финансами и дневником — нечёткая ценность.

### Главный экран
Текущая дата, недельная лента, категории фильтров, пустое состояние, нижняя навигация с 5 вкладками.

![Habit Tracker главный экран](competitor_screenshots/habit_tracker_main_after_skip.png)

![Habit Tracker главный экран без попапа](competitor_screenshots/habit_tracker_close_popup.png)

**Плюсы:**
- Недельная лента и категории удобны.
- Нижняя навигация даёт быстрый доступ к разным модулям.

**Минусы:**
- «Что нового 3.3.1» появляется при первом запуске — раздражает.
- Интерфейс перегружен: 5 вкладок + фильтры + категории.
- Пустое состояние не предлагает действие.

### Добавление привычки
Приложение не отреагировало на ADB-taps; предположительно использует Flutter/React Native с жестами. По onboarding видно, что создание привычки предполагает выбор типа (привычка, задача, настроение, финансы), иконки, частоты, напоминаний.

**Вывод для NOVAX:**
- Не копировать «всё в одном».
- Сделать создание привычки максимально быстрым: 1 экран, 3–4 поля.

## 5. Стратегические выводы для NOVAX Habits

### Что копировать
1. **Loop:** скорость добавления привычки, минимализм, отсутствие paywall на старте.
2. **Productive:** персонализация через 1–2 вопроса, визуальный стиль (фиолет/индиго), чёткое время напоминаний.
3. **Habit Genius:** карусель onboarding с 2–3 слайдами максимум, если нужно объяснить киллер-фичи.

### Чего избегать
1. **Согласие на трекинг** — NOVAX не трекит, поэтому такого экрана не будет.
2. **Ранний paywall** — не показывать до окончания trial.
3. **Перегруз функциями** — без задач, финансов, дневника.
4. **Пустое состояние без CTA** — добавить кнопку «Добавить первую привычку».

### Рекомендации по UX
- **Onboarding:** 2 экрана (ценность) + 1 вопрос (цель) → главный экран.
- **Главный экран:** сегодняшняя дата, недельная лента, список привычек, FAB для добавления, индикатор streak.
- **Добавление привычки:** название, иконка/цвет, частота, время напоминания. Всё остальное — в «Дополнительно».
- **Пустое состояние:** иллюстрация + CTA + короткая подсказка.
- **Уведомления:** запрос разрешения сразу после создания первой привычки, не на старте.

### Точки дифференциации
- **Streak Freeze** — 1 grace-день в неделю (не у Loop/Productive).
- **Weekly Challenge 5/7** — цель на неделю, а не только streak.
- **Trial 30 дн. → разовая покупка 159 ₽** — проще и доступнее, чем подписки конкурентов.
- **Нет трекинга и облака** — offline-first, приватность.
- **Виджет fast-follow #1** — после релиза.
