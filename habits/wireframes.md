# Wireframes NOVAX Habits / Привычки+

> MVP-фокус: onboarding → главный экран → добавление привычки → paywall (после trial).
> Label: RU `Привычки +`, EN `Habits +`. Store cards product-first: `Привычки+ NOVAX — трекер` / `Habits+ NOVAX — habit tracker`.

---

## 1. Onboarding

### Экран 1.1 — Welcome
- **Цель:** объяснить ценность за 3 секунды.
- **Элементы:**
  - Логотип / иллюстрация (фиолет/индиго).
  - Заголовок: «Вырабатывайте привычки».
  - 3 bullets:
    - Streak Freeze — 1 grace-день в неделю.
    - Weekly Challenge 5/7 — цель на неделю.
    - 30 дней бесплатно, затем 159 ₽ разово.
  - Кнопка «Начать» (primary).
  - Ссылка «Уже есть покупка? Восстановить» (small, secondary).

### Экран 1.2 — Цель
- **Цель:** 1 вопрос для персонализации (как у Productive, но короче).
- **Элементы:**
  - Заголовок: «Чего вы хотите достичь?»
  - 4 большие карточки-варианта:
    - Здоровье
    - Продуктивность
    - Спорт
    - Другое
  - Кнопка «Пропустить» вверху.

### Экран 1.3 — Уведомления (показывать ПОСЛЕ создания первой привычки)
- **Цель:** запросить разрешение в контексте, а не на старте.
- **Элементы:**
  - Иллюстрация.
  - Текст: «Напомним о привычках в нужное время».
  - Кнопка «Разрешить уведомления».
  - Кнопка «Не сейчас».

## 2. Главный экран (Home)

### AppBar
- Слева: иконка меню/настроек.
- Центр: `appTitle` (`Привычки +` / `Habits +`).
- Справа: иконка премиума (если trial активен / истёк).

### Недельная лента
- Горизонтальный список дней: Пн, Вт, Ср, Чт, Пт, Сб, Вс.
- Каждый элемент: день недели (буква), число, индикатор прогресса (точка/кольцо).
- Выбранный день выделен фиолетовым фоном.

### Список привычек
Карточка привычки:
- Слева: цветная плашка с иконкой.
- Центр: название, частота, текущий streak (🔥 5).
- Справа: круглый чекбокс для отметки выполнения.
- Long-press: контекстное меню (редактировать, удалить).

### Пустое состояние
- Иллюстрация / иконка.
- Текст: «У вас пока нет привычек».
- Кнопка «Добавить первую привычку».

### FAB
- Круглая кнопка «+» внизу справа.

## 3. Добавление / редактирование привычки

### AppBar
- Слева: стрелка назад.
- Центр: «Новая привычка» / «Редактировать».
- Справа: «Сохранить».

### Поля формы
1. **Название** — TextField, placeholder: «Например, пить воду».
2. **Иконка + цвет** — горизонтальный список пресетов (иконка на цветном круге).
3. **Частота** — сегментированный контроль:
   - «Каждый день» (по умолчанию).
   - «Выбрать дни недели» — ряд кнопок Пн-Вс.
4. **Напоминание** — переключатель + TimePicker.
5. **Дополнительно** (раскрывающийся блок):
   - Вопрос для уведомления (placeholder: «Вы уже ... сегодня?»).
   - Заметки.

### Валидация
- Название обязательно.
- Минимум 1 день в неделю.

## 4. Детали привычки

- AppBar с названием.
- Большая карточка: streak, лучший streak, completion rate.
- Календарь на текущий месяц с отметками.
- Кнопки: «Редактировать», «Удалить в корзину».

## 5. Paywall

- **Показывать:** после окончания 30-дневного trial.
- **Элементы:**
  - Заголовок: «Продолжайте строить привычки».
  - Bullets: Streak Freeze, Weekly Challenge, напоминания, виджет.
  - Цена: 159 ₽ / $2.99 (one-time).
  - Кнопка «Купить».
  - Кнопка «Восстановить покупку».
  - Ссылка «Условия использования / Политика конфиденциальности».
