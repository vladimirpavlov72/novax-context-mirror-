## Симптом

Пользователь отключил(а) напоминания (выключатель/настройка в приложении),
но локальные уведомления продолжают приходить.

## Гипотезы для проверки (не диагноз)

1. Тумблер «напоминания» пишет флаг, но планировщик (AlarmManager/
   flutter_local_notifications/zonedSchedule) не отменяет уже запланированные
   уведомления — отмена только для новых.
2. Отключается глобальный выключатель, но напоминания планируются на уровне
   отдельных привычек со своим флагом (обход глобального).
3. После правок 16.10 (USE_EXACT_ALARM, exact-режим) уведомления
   перепланируются при каждом старте и игнорируют флаг.
4. «Убрала напоминания вообще» = удалила привычки/время, а запланированный
   аларм остался висеть.

## DoD

1. Воспроизвести на A52 и эмуляторе: включить напоминания → получить →
   выключить → НЕ получать (проверить минимум 2 цикла напоминания).
2. Проверить все пути отключения: глобальный тумблер, per-привычка, удаление
   времени напоминания, удаление привычки.
3. Юнит-тест на «флаг off → cancelAll/отмена по id» (по образцу дисциплины
   Z-цикла v2.3.0).
4. Регрессия: после фикса напоминания всё ещё срабатывают при ВКЛ (16.10
