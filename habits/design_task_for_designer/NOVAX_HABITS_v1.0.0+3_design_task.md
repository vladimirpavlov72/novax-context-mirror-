## 2. Ограничения (нельзя нарушать)

| Ограничение | Пояснение |
|---|---|
| **Flutter + Material 3** | Используем стандартные Material-компоненты. Кастомные шейдеры, сложные анимации — нет. |
| **Архитектура** | `StatefulWidget + ValueNotifier + SharedPreferences`. Сервисы — синглтоны. **Нельзя:** BLoC, Riverpod, Provider, GetX, Firebase, go_router. |
| **Локализация** | Все строки в ARB-файлах. Хардкод-строк в UI — запрещён. Тексты должны быть короткими, чтобы влезали в 12 языков. |
| **Биллинг** | Только `flutter_rustore_pay` (vendored). Никаких других платёжных SDK. |
| **Без трекинга и рекламы** | Никаких Firebase Analytics, Crashlytics, рекламных сетей. |
| **pub.dev заблокирован** | Все пакеты — из `C:\dev\vendor\packages\`. Новые зависимости добавлять только через vendor-процесс. |
| **Бюджет времени** | Правки должны укладываться в 1–2 дня работы разработчика. |

## 5. Текущая тема и цвета

Источник: `lib/app.dart`

- **Seed color:** `#6366F1` (indigo).
- **Светлая тема:** `ColorScheme.fromSeed(seedColor: 0xFF6366F1, brightness: Brightness.light)`.
- **Тёмная тема:** `ColorScheme.fromSeed(seedColor: 0xFF6366F1, brightness: Brightness.dark)`.
- **Material 3:** включён (`useMaterial3: true`).
- **Дефолт:** светлая тема.

**Вопросы к дизайнеру:**
1. Seed color `#6366F1` подходит для приложения о привычках? Может, взять что-то более "живое" (зелёный, оранжевый, синий)?
2. Достаточно ли контраста в светлой теме?
3. Нужна ли более выраженная брендовая палитра, а не дефолтная Material?

## 9. Конкретные вопросы к аудиту

Ответь, пожалуйста, по каждому пункту:

1. **Общее впечатление:** приложение выглядит как MVP или как готовый продукт?
2. **Цветовая схема:** цвета подходят для темы привычек? Нужен ли ребрендинг цвета?
